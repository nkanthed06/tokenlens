## Commit Principles

- Each change is independently reviewable and leaves the project usable.
- Feature work is followed by focused tests or reliability hardening.
- Both author and committer timestamps use noon Pacific time on the scheduled
  date.
- The repository's original initial commit remains unchanged and is not part of
  the 36-commit backlog.
